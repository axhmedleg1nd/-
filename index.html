Символы: * = разделитель, # = пробел, + = точка,
% = восклицательный знак,
( или ) = вопросительный знак,
[ = открывающая скобка, ] = закрывающая скобка
√ = инверсия регистра: вне CAPS — делает букву ЗАГЛАВНОЙ,
внутри { } — делает букву строчной.
{ } = CAPS: всё внутри заглавное
Цифры: *1* — переключение в режим цифр, ещё раз *1* — обратно
Правило: к существительным добавляется суффикс «-ость» (кот → котость, диван → диваность).
Глаголы, предлоги, местоимения и союзы не меняются.

Исключения:
я → ч
кто → кто (без изменений)
батя → батч
дед → дод / додус (случайно)
друг → друн / друнность (случайно)
чекунец, чекушка → без изменений

Определение «это существительное или нет» — приблизительное (по списку служебных слов и типичным окончаниям), не настоящая грамматика.

а=a, б=b, в=v, г=g, д=d, е=e, ё=yo, ж=zh, з=z, и=i, й=i,
к=k, л=l, м=m, н=n, о=o, п=p, р=r, с=s, т=t, у=u, ф=f,
х=kh, ц=c, ч=ch, ш=sh, щ=sh, ъ=(опускается), ы=i, ь=(опускается),

Заглавная буква — заглавная замена целиком (Ю → YU, Ж → ZH).
