📱 Переводчик на «Цифирный»

Раскладка: 2=АБВГ, 3=ДЕЁЖЗ, 4=ИЙКЛ, 5=МНОП, 6=РСТУ, 7=ФХЦЧ, 8=ШЩЪЫ, 9=ЬЭЮЯ
Символы: * = разделитель, # = пробел, + = точка,
% = восклицательный знак,
( или ) = вопросительный знак,
[ = открывающая скобка, ] = закрывающая скобка
√ = инверсия регистра: вне CAPS — делает букву ЗАГЛАВНОЙ,
внутри { } — делает букву строчной.
{ } = CAPS: всё внутри заглавное
Цифры: *1* — переключение в режим цифр, ещё раз *1* — обратно
