📱 Правила Циферного T9:
• Кнопки: 2=АБВГ, 3=ДЕЁЖЗ, 4=ИЙКЛ, 5=МНОП, 6=РСТУ, 7=ФХЦЧ, 8=ШЩЪЫ, 9=ЬЭЮЯ
• Символы: # — пробел, * — разделитель повторных букв с одной кнопки.
• Регистр и цифры: √ — переключение заглавной буквы, *1* — ввод цифр.
• Знаки препинания: + = ., % = !, ( = ?
🏢 Правила Муринского языка (Бурмалда):
• Словарные замены: «я» → «ч», «друг» → «друн», «папа»/«батя» → «батч», «дед» → «дод», «сын» → «сыр», «кто» → «кьо», «учитель» → «учиха», «физрук» → «физрун», «туман» → «фог», «кот» → «котость», «собака» → «собака-бурмалдака», «заяц» → «заяц-бурмалдаяц».
• Суффиксы: К остальным существительным прибавляется суффикс «-ность» (со сбросом конечной гласной/«й»): «стене» → «стенность», а к словам на согласную суффикс «-ность» добавляется напрямую: «паук» → «паукность».
• Исключения: к глаголам (пришёл, гуляет, буду) и словам вроде «хорошо» суффикс не добавляется.
🔊 Правила Bass (Транслит):
• Алфавит: ц=c, щ=sh', ь=', й=i, ж=zh, х=kh, ч=ch, ш=sh, ё=yo, ю=yu, я=ya.
• Полная транслитерация с сохранением заглавных букв.
🥺 Правила Пикми:
• Превращение слов в уменьшительно-ласкательные («кот» → «котик»).
• Заикание в начале случайных слов (п-приветик), растягивание гласных (приветииик), милые вставки между словами (ня, мур~), тильды ~~ и изобилие милых эмодзи!
🗿 Правила MOGGерского языка:
• Автоматическая замена названий городов и обращений («Москва» → «MOGGсква», «парень» → «Mogger»).
• Каждая фраза получает статус верховного самца [MOGGED].
🌸 Правила Тсундере:
• Превращает обычный текст в эмоциональные фразы с заиканием и милой агрессией!
• Больше словарных замен, случайное заикание у любых слов и множество разных тсундере-концовок («Не то чтобы мне это нравилось! 😤»).
• 🎵 Своя музыка: положите файл tsundere-music.mp3 (или .ogg) рядом с index.html в репозитории — заиграет автоматически при включённой музыке.
0️⃣1️⃣ Правила Двоичного кода:
• Каждый символ кодируется 8-битным байтом в UTF-8 (кириллица занимает 2 байта на букву).
• Байты разделяются пробелом.
• Обратный перевод собирает байты обратно в UTF-8 текст.
🅰️ Правила языка «ААААААА»:
• Между случайными словами по всему тексту (а не только в конце предложений) вставляются серии из буквы «А» случайной длины (от 1 до 10).
• Количество таких вставок в тексте не ограничено.
• Обратный перевод удаляет «слова», целиком состоящие из заглавной буквы «А».
